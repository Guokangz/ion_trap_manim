# Changelog

## Final presentation version

This version corresponds to the final Manim animation workflow used for the three-minute academic talk:

**量子调控：如何用电场困住一个离子？**  
**Quantum Control: How Can an Electric Field Trap an Ion?**

Major updates:

- Refined the full four-scene explanation of the linear Paul trap mechanism.
- Improved the transition from four-rod electrodes to the radial RF quadrupole field.
- Added a consistent RF driving inset to explain opposite-phase RF voltages.
- Improved the transition from the 2D quadrupole potential to the 3D saddle potential.
- Added stable fixed-in-frame coordinate insets for visual orientation.
- Refined the driven saddle comparison:
  - low-frequency switching leads to escape;
  - high-frequency switching produces bounded motion.
- Refined the pseudopotential scene:
  - high-frequency alternating saddle potentials are visualized as an effective time-averaged pseudopotential;
  - final ion motion is shown near the bottom of the pseudopotential well.
- Added scripts for preview rendering, PPT-quality rendering, full-video rendering, and cleaning outputs.
- Updated README with project motivation, tools, environment, rendering commands, and physics notes.
- Generated PPT-friendly MP4 outputs and a full combined MP4 locally; generated media are intentionally ignored by Git.

Notes:

- Rendered videos are not tracked in Git.
- The repository tracks source code, scripts, and documentation only.
- The project used an AI-assisted coding workflow, with final physical narrative, visual design, and scientific terminology manually reviewed and revised.
